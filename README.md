## Context

This is my master's dissertation project. I made a simulation game where the player constructs a city, while virtual people go about their lives. 
It was inspired by SimCity and Cities: Skylines, and integrates some of the modules I studies throughout my course, mainly:

- Intelligent system techniques
- Network science
- Adaptive systems

## Background

In my undergraduate final year dissertation, I experimented with performant pathfinding techniques.

## What I Learnt

The focus of the project was to simulate agents in a performant way. I learnt the following:

- How to use the Unity game engine
- How to construct a video game user interface
- About user interaction and what makes a game fun (the theory of funology)
- How games like Cities: Skylines achieve performance
- What makes an agent _intelligent_ and what intelligence means (the theory of intelligence)
- How intelligence can be simulated in silico, this included
  - Pathfinding or route-finding
  - Action selection
- How to make and texture 3D models (using Blender)

## Future Improvements

In the report, I outlined specific future improvements, such as the need for user feedback and how that could be integrated, as well as new gameplay features such as additional buildings.
